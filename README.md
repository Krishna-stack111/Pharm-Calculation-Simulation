# PharmCalc | Pharmaceutical Calculations Simulator

An interactive web app for pharmacy students, educators and formulation scientists. Every result is shown with its equation and the numbers used, so each answer can be checked at a glance.

## Features
- **Molarity, molality, normality** from mass, molecular weight, volume and solvent mass
- **Percentage concentrations**: % w/v, % w/w and % v/v
- **Conversion** between % w/v, % w/w, molarity, molality and normality
- **Stock strength and dilution**: molarity of a concentrated stock (e.g. an acid sold as % w/w) and the volume to measure for a target solution (C1V1 = C2V2)
- **Mass, volume and density** solver
- Real-time results, works on mobile, light and dark mode

## Run it
Open `index.html` in a browser. No install or build step is needed.

## Host it free
1. Push this folder to a GitHub repository.
2. Go to **Settings > Pages**, choose the `main` branch and the root folder, then save.
3. Your live app appears at `https://<your-username>.github.io/<repo-name>/`.
